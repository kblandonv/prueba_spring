# prueba_spring

Proyecto Spring Boot (Java 17, Maven, PostgreSQL).

## Requisitos
- JDK 17+
- Maven (o el wrapper `./mvnw`)
- PostgreSQL + DBeaver
- Git

## Base de datos
Crear la BD `prueba` y ajustar credenciales en `src/main/resources/application.properties`.

## Ejecutar
```
./mvnw spring-boot:run
```
